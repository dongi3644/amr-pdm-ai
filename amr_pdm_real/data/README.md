# 여기에 CSV를 넣으세요

`실행/0_아두이노_기록.py`로 기록하면 이 폴더에 자동으로 저장됩니다.

로봇 1대 = CSV 파일 1개 (같은 `robot` 이름의 파일은 이어 붙임). 필수 열은 `time`(초)과 MPU6050의 `ax`, `ay`, `az`, `gx`, `gy`, `gz`이고, INA219의 `current`, `voltage`는 있으면 전류·배터리 감시에 씁니다.
자세한 형식은 [../README.md](../README.md)의 "데이터 형식"을 보세요.
`시간, ax~gz(원래값도 됨), 엔코더 4개, 모터 명령, 전류, 전압` 형식을 자동으로 맞춰 읽습니다 (µs·ms, mA·mV, 단위 붙은 열 이름도 됨. 같은 곳의 표 참고).
한 기록은 **6분 이상**이어야 합니다 (처음 5분이 그 로봇의 정상 기준).

이 폴더의 CSV는 GitHub에 올라가지 않습니다(`.gitignore`). 데이터는 팀원끼리 따로 주고받으세요.
