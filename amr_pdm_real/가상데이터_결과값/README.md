# 가상 데이터 결과값 (코드 점검용 · 성능 아님)

> **이 폴더의 숫자는 발표·성능 자료로 쓰지 않습니다.** 진동·고장·엔코더 신호를 사람이 식으로 만든 가상 로봇 결과입니다.
> 실제 성능은 실측 CSV로 `python run.py train`을 돌려 나온 교차검증 수치입니다.
