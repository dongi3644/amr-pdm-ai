> **이 %는 발표·성능 자료로 쓰지 않습니다.** 진동과 고장을 사람이 식으로 만든 가상 로봇이라 실제 로봇 성능이 아닙니다.

- 시험: 학습에 쓰지 않은 가상 로봇 45대, 걸린 시간 2.8분
