> **이 %는 발표·성능 자료로 쓰지 않습니다.** 진동과 고장을 사람이 식으로 만든 가상 로봇이라 실제 로봇 성능이 아닙니다.

- 시험: 학습에 쓰지 않은 가상 로봇 45대, 걸린 시간 5.2분

- 복잡한 고장 · 어려운 정상 묶음의 낮은 수치는 그 경우에 이 구조가 약하다는 신호입니다. 실측 기록 계획에 반영하세요
