# 실행 방법 (VS Code · Visual Studio)

`실행` 폴더의 파일을 하나 열고 실행 버튼만 누르면 됩니다. 각 파일은 프로젝트 가상환경(`.venv`)의 Python으로 실제 코드를 실행하므로, IDE가 어떤 Python을 골라 두었든 결과가 같습니다.

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `1_환경설치.py` | 처음 한 번. `.venv`를 만들고 패키지 설치 (몇 분) |
| 2 | `2_시뮬레이션_학습.py` | 시뮬레이션 데이터로 학습·평가 (모델이 이미 있으면 건너뛰어도 됨) |
| 3 | `3_대시보드.py` | 대시보드를 열고 브라우저에서 http://localhost:8501 표시. 끝낼 때는 중지 버튼 |
| 4 | `4_내데이터_검사.py` | `user_data` 폴더의 CSV 형식 검사 |
| 5 | `5_내데이터_학습.py` | (선택) 내 데이터로 학습 |
| 6 | `6_내데이터_진단.py` | 내 데이터 진단 → `reports/user/` |
| - | `예시데이터_만들기.py` | 실제 파일이 없을 때 시뮬레이터로 예시 CSV 생성 |
| - | `로봇1대_시뮬레이션_진단.py` | 대시보드 없이 콘솔로 빠르게 확인 |

설정값(학습에서 뺄 로봇, 진단 모델 등)은 각 파일 맨 위에 있으니 고친 뒤 실행하세요. 데이터 형식은 `DATA_FORMAT.md`를 보세요.

## VS Code

1. 상위 폴더의 `AMR_고장예지AI.code-workspace`를 더블클릭하거나, **파일 → 폴더 열기**로 `amr_pdm` 폴더를 엽니다. (`AMR_고장예지AI_코드모음` 폴더를 열면 실행 설정이 보이지 않습니다.)
2. `실행/1_환경설치.py`를 열고 오른쪽 위 ▷ 버튼을 누릅니다.
3. 그다음부터는 `실행` 폴더의 파일을 열고 ▷를 누르거나, 왼쪽 **실행 및 디버그**에서 항목을 골라 F5를 누릅니다. 실행 및 디버그 항목은 `.venv`로 바로 실행되어 중단점이 걸립니다.

오른쪽 아래에 Python 인터프리터를 고르라는 알림이 나오면 `.venv`를 고르세요.

## Visual Studio 2022

1. **파일 → 열기 → 폴더**로 `amr_pdm` 폴더를 엽니다.
2. 솔루션 탐색기에서 `실행/1_환경설치.py`를 오른쪽 클릭 → **시작 항목으로 설정** → **Ctrl+F5**(디버그하지 않고 시작).
3. 다른 단계도 같은 방법으로 시작 항목을 바꿔 Ctrl+F5로 실행합니다.

Visual Studio에는 Python 개발 워크로드가 설치되어 있어야 하며, 이 PC에는 설치되어 있습니다.

## 자주 생기는 문제

- **"가상환경이 없습니다"**: `1_환경설치.py`를 먼저 실행하세요.
- **대시보드가 "모델 파일이 없습니다"라고 나옴**: `2_시뮬레이션_학습.py`를 먼저 실행하거나, 대시보드에서 "내 데이터"를 고르고 학습하세요.
- **8501 포트가 이미 사용 중**: 이전 대시보드가 아직 켜져 있습니다. 터미널에서 중지하거나 `3_대시보드.py`의 `PORT`를 바꾸세요.
