# 여기에 실측 CSV를 넣으세요 (GitHub에 올라가지 않음)

## 가상 성능 시험 (`가상테스트/성능시험.py`)
팀 실측 폴더 4개를 **폴더째로** 이 아래에 둡니다 (팀원에게 따로 받기).

```
third_model/data/
  정상 데이터_공3옥상/            ← 공3옥상 정상 (11.13)
  정상 데이터_공3옥상(11.16)/     ← 공3옥상 정상 (11.16)
  정상 데이터_욧골(11.15)/        ← 욧골 정상
  고장 데이터_욧골/               ← 욧골 앞 오른쪽 바퀴 테이프 고장
```

가상 로봇은 실행할 때 이 실측 기록을 재료로 컴퓨터 안에서 새로 만듭니다 (파일로 저장하지 않음). 같은 데이터 · 같은 seed면 누구 컴퓨터에서든 같은 로봇이 만들어집니다.

## 실측 학습 · 진단 (`python run.py train` · `diagnose`)
- 한 기록 = CSV 한 파일, 6분 이상 (처음 5분 = 그 로봇의 정상 기준)
- 열: `t_us, ax, ay, az, mV, mA, spd, enc2[, enc1, enc3, enc4], label` (팀 기록 형식 그대로 읽힘)
- 이 폴더의 CSV는 GitHub에 올라가지 않습니다 (`.gitignore`).
