# 최종 성능과 시험 조건 (11/20)

AMR 바퀴 고장 예지 AI(third_model)의 최종 성능과, 그 숫자가 **어떤 조건에서** 나왔는지만 따로 모은 문서입니다.

> **한 줄로:** 팀이 기록한 실측 데이터로 만든 '가상 로봇'으로 학습하고, 학습에 쓰지 않은 가상 로봇 166대로 시험한 결과입니다. 개발 중 시험 결과를 보고 특징과 시험 조건을 바꿨으므로 완전히 독립된 시험은 아닙니다.
> 실제 로봇의 성능이 아니므로, 실측 고장을 길게 기록해 다시 확인해야 합니다.

---

## 1. 최종 성능

| 지표 | 결과 | 대수 | 뜻 |
|---|---|---|---|
| ① 전체 정답률 | **97.6%** | 166대 중 162대 | 고장 로봇은 고장으로, 정상 로봇은 정상으로 맞게 판정 |
| ② 아는 고장 찾기 | **96.3%** | 54대 중 52대 | 학습한 고장 (바퀴 불균형 · 체결 풀림 · 마찰 증가) |
| ③ 처음 보는 고장 찾기 | **94.9%** | 39대 중 37대 | 학습에 없던 고장 (기어 마모 · 바퀴 찍힘 · 새 주파수 베어링) |
| ④ 고장 원인 맞히기 | **96.6%** | 찾은 89대 중 86대 | 아는 고장은 종류, 처음 보는 고장은 '처음 보는 이상'으로 알리면 맞음 |
| ⑤ 잘못 울린 경보 | **0.0%** | 정상 73대 중 0대 | 멀쩡한 로봇인데 고장이라고 한 비율 (낮을수록 좋음) |

**틀린 것**
- 놓친 고장 4대 (3대는 약하고 0.46은 중간 정도): 바퀴 찍힘 2대(최종 세기 0.46 · 0.22), 마찰 증가 1대(0.20), 바퀴 불균형 1대(0.23)
- 원인을 틀린 3대: 체결 풀림 1대 · 바퀴 찍힘 2대를 '바퀴 불균형'으로 봄 (고장이라는 것은 맞게 알림)

**읽는 법**
- 100%나 0%는 해당 로봇을 모두 맞힌 값입니다. 대수가 적으면(수십 대) 1대 차이로 2~3%p씩 움직이므로 '대략 95~98%'로 읽는 것이 맞습니다.

## 2. 시험 조건

### 2-1. 데이터
| 항목 | 내용 |
|---|---|
| 실측 데이터 | 팀이 아두이노로 기록한 4폴더: 공3옥상 정상 2 · 욧골 정상 1 · 욧골 테이프 고장(불균형) 1 |
| 센서 | MPU6050 가속도 3축(약 480 Hz) · INA219 전류 · 전압 · 엔코더 |
| 나누기 | 실측 파일을 **학습 40 · 검증 14 · 시험 19개**로 나눔 → 주행 조각은 학습에 안 쓴 파일에서만 뽑음. 단, 정지 기록 3개 · 테이프 고장 모양 · 생성 방식은 학습과 공유 |

### 2-2. 가상 로봇 만드는 법
| 부분 | 어디서 오나 |
|---|---|
| 평소 진동 · 전류 · 전압 · 멈춤 구간 | **실측** 정상 기록의 2~6초 조각을 이어 붙임 (크기: 조각 ±5%, 로봇 전체 ±15%, 축마다 ±15%) |
| 바퀴 불균형 고장 | **실측 보정**: 테이프 고장 기록에서 잰 '고장 − 정상' 진동 증가분 |
| 체결 풀림 · 마찰 · 기어 · 찍힘 · 새 주파수 베어링 | **가정**: 모양은 식으로, 세기는 실측 불균형에 맞춤 |
| 엔코더 4개 | **가정**: 바퀴 회전 식 (실측 엔코더는 enc2 1개뿐) |
| 고장 시작 · 진행 · 간헐 · 복합 | 로봇마다 무작위 조건 |

### 2-3. 학습 · 검증 · 시험 로봇
| 단계 | 로봇 | 하는 일 |
|---|---|---|
| 학습 | 가상 로봇 44대(고장 27대) + 무작위 이상을 넣은 정상 복사본 11대 | AI 2개 학습 |
| 검증 | 가상 로봇 83대 (아는 고장만) | 판정 설정 고르기 (**시험 로봇은 보지 않음**) |
| 시험 | 가상 로봇 **166대** = 고장 93대(그중 **학습에 없던 고장 39대**) + 정상 73대 | 점수 매기기 |

- 고장 세기: 최종 세기 = 진행 정도 × 로봇별 배율 × 추가 배율(0.5~1.0). 시험 주 고장은 0.14~0.82 (1.0 = 속도 5에서 테이프만큼 늘어난 진동 에너지, 속도 영향은 빼고 셈)
- 헷갈리는 정상 포함: 바닥 바뀜 · 짐 실음 · 저전압 · 속도 바뀜

### 2-4. AI와 판정 설정
| 항목 | 값 |
|---|---|
| AI | 주파수 모양 오토인코더(비지도) + 랜덤포레스트(지도) **2개**, 보조로 바퀴 점수(규칙) |
| 특징 | 1초마다 121개 (진동 · 바퀴 · 엔코더 1회전 속도 모양 · 주파수 모양 · 1회전 박자) |
| 1분 점수 | 1초 점수의 중앙값과 상위 10% × 0.65 중 큰 값 |
| 경보 | **주의 2.0점 · 경고 6점**, 2번 연속일 때 상태 변경 |
| 원인 | 확신 0.3 미만이면 '원인 미확정 (처음 보는 이상)' |
| 고른 방법 | 모두 검증 로봇으로 고름 (`config.py`에 저장) |

### 2-5. 맞음으로 세는 기준
- **고장 로봇:** 고장이 시작된 뒤에 '주의' 이상을 알리면 찾은 것
- **정상 로봇:** 기록 내내 경보가 한 번도 없어야 맞은 것 (한 번이라도 울리면 잘못 울린 경보)
- **원인:** 아는 고장은 종류가 맞아야, 처음 보는 고장은 '처음 보는 이상'(새 주파수 베어링은 '마찰 증가'도)이면 맞음

## 4. 주의할 점
- **가상 로봇 결과입니다.** 실측 고장은 테이프 불균형 20초뿐이라, 다른 고장의 진동 모양은 가정했습니다.
- 엔코더 4개도 가정입니다 (실측은 1개). 엔코더 특징이 빠지면 성능이 달라질 수 있습니다.
- 최종 세기 0.2 근처의 약한 고장은 놓칠 수 있고, 중간 정도(0.46)도 1대 놓쳤습니다.
- 시험 로봇은 새로 만들었지만(seed 2031), 개발 중 시험 결과를 보고 특징과 이 시험 조건을 바꿨으므로 완전히 독립된 시험은 아닙니다. 고치는 데 쓴 로봇(seed 2027)의 결과는 [README 5-1절](README.md)에 따로 있습니다.
