# 변경 사항: 가속도 + 엔코더(enc2) + 속도(spd)로 학습

팀 스케치 기록(t_us, ax, ay, az, mV, mA, spd, enc2)을 그대로 학습할 수 있게 고쳤습니다.

## 모델에 들어가는 값
- 진동 18개: ax, ay, az 각각 rms·kurt·crest·저/중/고주파 (각속도 gx·gy·gz는 쓰지 않음)
- 엔코더 2개 (enc2 = 앞 오른쪽 바퀴): 명령 대비 속도(fr_speff), 속도 출렁임(fr_sprip)
- 모터 명령 1개: spd
- 전류·전압(mA, mV)은 지금처럼 AI가 아니라 전류·배터리 규칙 감시에만 사용

## 고친 파일
- config.py: VIB_CHANNELS = ["ax","ay","az"], PARTIAL_ENCODER_FEATURES = True, CMD_FEATURE = True
- pipeline/dataio.py: 엔코더마다 1초 창의 시간·누적 펄스를 따로 저장
- pipeline/features.py: 엔코더 1~3개일 때 쓰는 특징(part_enc_features), 특징 선택(choose_feats)
- pipeline/workflow.py: 진단 기록에 학습 때 쓴 엔코더·spd가 없으면 건너뛰고 이유 출력
- pipeline/infer.py: 새 특징의 한글 이름
- run.py: check의 엔코더 안내 문구

## 주의
- 기록은 6분 이상이어야 합니다 (처음 5분으로 로봇마다 정상 기준을 만듦). 지금 받은 정상 파일 2개는 각 10초라 학습에 쓸 수 없습니다.
- 진단할 기록에도 enc2와 spd가 있어야 합니다.
- 나중에 각속도까지 기록하면 VIB_CHANNELS를 ["ax","ay","az","gx","gy","gz"]로 되돌리고 train부터 다시 하세요.
- 엔코더 값을 각속도로 바꿔 넣지 않습니다.

# 변경 사항 2: 남은 시간(잔존 시간) 예측·칼만 필터 제외

- 모델은 건강 점수 → 상태(정상·주의·경고)와 원인(어느 바퀴, 무슨 고장)만 냅니다.
- 지운 것: models.py의 kalman_forecast·trend_forecast, workflow.py의 tune_kalman·예측 오차 평가, config.py의 KALMAN·KALMAN_GRID·TREND_PERIODS
- 진단 표에서 '정지 위험까지(분)'·'빠르면(분)' 열, 결과 요약에서 '남은 시간 예측' 줄·절이 빠졌습니다.
- '정지 위험 전 경고'(고장 정도 0.8 전에 경고가 떴는가)는 감지 성능이라 그대로 둡니다.
- 예전에 학습한 model_bundle.joblib은 그대로 열리지만, train을 다시 돌려 새로 만드는 것을 권합니다.
