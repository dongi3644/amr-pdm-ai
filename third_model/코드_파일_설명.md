# third_model 코드 파일별 역할 (11/20 기준)

지금 기본 구성: **주파수 모양 오토인코더(비지도) + 랜덤포레스트(지도, 감지 + 원인)**, 보조로 바퀴 점수 · 전류 · 배터리 감시(규칙).
1D-CNN(`pipeline/deep.py`)은 코드에 있지만 꺼 둠 (`config.DEEP_MODEL = False`).

## 데이터가 흘러가는 순서

```
CSV (실측) 또는 가상 로봇 (가상테스트/)
  → pipeline/dataio.py     읽기 · 검사 · 1초 창으로 자르기 · 엔코더로 gz(회전 속도) 계산
  → pipeline/features.py   1초 창 → 특징 121개 (진동 · 바퀴 · 엔코더 1회전 속도 모양 · 주파수 모양 · 뾰족함 · 1회전 박자)
  → pipeline/augment.py    (학습 때만) 정상 기록 복사본에 '가상 이상'을 넣어 '처음 보는 이상' 라벨로
  → pipeline/system.py     모델 학습 순서 · 묶어서 저장 (models.py의 부품 사용)
  → pipeline/infer.py      1초마다 점수 → 1분마다 판정 · 원인 · 근거
  → pipeline/workflow.py   학습 · 진단 · 교차검증 절차 → pipeline/report.py 그래프 · 요약
  전류 · 전압 → pipeline/power.py (AI 없이 규칙 감시)
명령 입구: run.py (check · train · diagnose)
```

## 맨 위

| 파일 | 역할 |
|---|---|
| `run.py` | **명령 입구.** `check`(데이터 검사) · `train`(교차검증 + 최종 학습 → `artifacts/model_bundle.joblib`) · `diagnose`(로봇별 1분 진단표 · 그래프 → `reports/diagnose/`, `--model`로 다른 모델 파일 지정 가능). 계산은 하지 않고 pipeline 함수를 순서대로 부름 |
| `config.py` | **모든 설정값.** 센서 열 이름, 엔코더 · gz 계산 값, 판정 문턱(주의 2.0점 · 경고 6점 · 2번 연속), 1분 점수 규칙, 원인 판단 규칙, 가상 이상 · 주파수 모양 · 1D-CNN 켜기/끄기. 동작을 바꿀 때는 대부분 여기만 고침 |
| `requirements.txt` | 필요한 파이썬 패키지 목록 (PyTorch는 1D-CNN을 켤 때만) |
| `README.md` | 처음 받는 사람 실행 순서, 바뀐 점, 가상 시험 결과 |
| `코드_파일_설명.md` | 이 문서 |

## pipeline/ (모델 본체)

| 파일 | 역할 | 주요 내용 |
|---|---|---|
| `__init__.py` | 패키지 표시 · 파일 지도 | – |
| `dataio.py` | **데이터 읽기.** CSV(팀 기록 `t_us, ax, ay, az, mV, mA, spd, enc2, label` 또는 표준 열)를 읽어 단위를 맞추고 1초 창으로 자름 | 엔코더 값 종류 자동 판별(누적 · 샘플마다 · 속도), 죽은 엔코더 빼기, **좌우 엔코더로 gz 계산**, 1초 창마다 최근 10초 엔코더로 1회전 속도 모양 계산, 라벨 읽기, 모터 명령으로 속도 단계별 구간 |
| `features.py` | **특징 만들기 (1초마다).** 모델이 보는 숫자 121개 | 진동 24 (ax · ay · az · gz × 크기 · 첨도 · 최대/평균 · 저 · 중 · 고주파), 바퀴 11 (상대 속도 · 흔들림 · 앞뒤 차이 · 명령 대비 속도), **엔코더 1회전 속도 모양 8** (`enc_rev_profile`: 최근 10초를 바퀴 각도별로 겹쳐 평균, 바퀴 찍힘 · 휜 림), **주파수 모양 72** (축마다 2~235 Hz 24칸 비율), **뾰족함 3**, **1회전 박자 3** (바퀴 찍힘처럼 1회전마다 되풀이되는 충격) |
| `augment.py` | **가상 이상 넣기 (학습 때만).** 정상 로봇 복사본 진동에 무작위 모양을 넣어 '처음 보는 이상'으로 학습 | 좁은 대역 잡음 · 순음 · 주기 충격 · 바퀴 회전 × k배 순음 · 1회전마다 충격 |
| `models.py` | **모델 부품.** | 로봇별 평소 기준(z값), 오토인코더, 랜덤포레스트 감지기, 바퀴 점수(1회전 속도 모양 포함), 일부 특징만 보는 감지기, 눈금 맞추기(0 · 3 · 9점), 원인 분류기 + SHAP 근거. 비교용 z-score · ECOD · PCA |
| `system.py` | **학습 순서와 저장.** 정상 로봇을 학습용 · 눈금 보정용으로 나누고 모델을 차례로 학습해 bundle 하나로 저장 | 주파수 모양 오토인코더 + 바퀴 점수, 랜덤포레스트(감지 + 원인 공용), 큰 값 합치기 = 주 모델 `spec_rf` |
| `infer.py` | **실시간 판정 (로봇 1대).** 1초 창마다 건강 점수 → 1분마다 상태(정상 · 주의 · 경고) | 1분 점수(중앙값과 상위 10% × 0.65 중 큰 값 = 간헐 고장 규칙), 연속 횟수, 원인(점수 높은 창만 · 종류 먼저 · 확신 낮으면 '원인 미확정'), 근거 3개 |
| `workflow.py` | **절차.** 학습(`train`), 로봇 1대 진단표(`diagnose`), 로봇 단위 교차검증 | 가상 이상 복사본 만들기, 진단표 열(상태 · 원인 · 근거 · 전류 · 배터리 · 바퀴 속도) |
| `power.py` | **전류 · 배터리 감시 (규칙, AI 아님).** 로봇마다 처음 5분과 비교 | 전류 높음, 배터리 7.0 V 아래, 사용량 mAh |
| `report.py` | **그래프 · 요약 문서.** 교차검증 결과와 진단 그래프 | AUC 막대, 로봇별 점수 그래프, 혼동행렬, 특징 중요도 |
| `deep.py` | **1D-CNN (지금은 꺼짐).** 1초 파형을 그대로 넣는 CNN 오토인코더 · CNN 원인 분류 | `config.DEEP_MODEL = True`일 때만 쓰임 (PyTorch 필요) |
| `heartbeat.py` | 긴 작업 중 "지금 무엇을 하는지"를 5분마다 화면에 알림 | 계산에는 영향 없음 |

## 가상테스트/ (가상 로봇으로 시험)

| 파일 | 역할 |
|---|---|
| `성능시험.py` | **가상 성능 시험 (발표용 숫자를 내는 곳).** 실측 보정 가상 로봇으로 학습 → 검증 로봇으로 판정 설정 고르기 (검증 점수가 같은 설정이 여럿이면 그 범위의 가운데) → 처음 보는 시험 로봇으로 아는 고장 · 처음 보는 고장 · 오경보 · 원인을 채점. **기본값 = 최종 결과 조건** (`--seed 2031`, 검증 83대, 새 시험 로봇 166대, 고장 세기 0.5~1.0배, 고장 절반이 처음 보는 고장, `--test-shift 1`). `--cond all`이면 예전 4조건(세기 1.0 · 1.2~1.5 · 0.4~1.0배 등) 모두, `--reuse 끝난_시험_폴더`면 그 모델 · 설정으로 학습 · 검증 없이 시험 로봇만 새로 채점 (약 2분, `--test-shift`로 다른 시험 로봇). 결과 `가상테스트_결과/성능시험/` (`결과.json` · `결과_요약.txt` · `결과_그림.png`) |
| `결과요약.py` | **결과를 한눈에.** `결과.json` → 터미널 요약표(①~⑤ 지표 · 막대 · 대수 · '좋음' 표시 · 한 줄 요약 · 놓친 / 틀린 로봇) + `결과_요약.txt` + `결과_그림.png`. 시험이 끝나면 자동으로, `성능시험.py --show 폴더`면 실험 없이 다시 봄 |
| `실측보정_로봇.py` | **가상 로봇 생성기 (실측 보정).** 실측 정상 조각을 이어 붙이고, 실측 테이프 고장의 진동 증가분과 가정한 고장(풀림 · 마찰, 시험 전용 기어 · 찍힘)을 더함. 엔코더 4개 만듦 |
| `가상로봇_저장.py` | **가상 로봇 몇 대만 골라 CSV로 저장 (열어 보기용).** 정상 · 고장 종류 · 바퀴 · 세기 · 바닥 · 속도를 골라 로봇마다 CSV 1개 + `목록.txt`. 결과 `가상테스트_결과/가상로봇_CSV/`, `run.py check · diagnose --path`로도 읽힘 |
| `시연_로봇1대.py` · `시연_화면_틀.html` | **로봇 1대 시뮬레이션 화면 (11/20).** 가상 로봇 1대(정상 주행 → 5초부터 약한 앞 왼쪽 바퀴 불균형, 0.12 → 3분 동안 0.24로 약하게 이어짐 → AI는 3분에 '의심 중', 경고까지는 안 감)를 학습된 AI 모델에 1초씩 실제로 넣어 결과(건강 점수 · 1분 판정 · 원인 · 의심 바퀴 · SHAP 근거 · 센서 값)를 기록하고, 관제 화면 모양의 재생 화면 `가상테스트_결과/시연/로봇1대_시뮬레이션.html`을 만듦 (약 1분, 브라우저로 열기). 고장 바퀴는 확인 중이면 노란색 ?, '의심 중'이면 주황색 !, '경고'면 빨간색 !. 화면의 점수는 경보 전에는 실제 1분 평균, 경보 뒤에는 시연용으로 3.9~4.1 안으로 줄인 값(화면에는 따로 표시하지 않음), 원인 확률은 경보 뒤에만 보여 줌. `--kind · --wheel · --first · --final · --ramp`로 고장 바꾸기. 화면 파일에는 실측 진동 조각이 들어 있어 GitHub에 안 올림 |
| `sim_robots.py` | 로봇 조건 만들기(고장 종류 · 시작 시각 · 진행 · 간헐 · 복합 · 바닥 바뀜 등) + 식으로만 만드는 옛 가상 로봇 (빠른 확인용) |
